## Development Contract
1. Do not code features that have not been designed.
2. Every step must run and pass before the next step.
3. Assistant provides architecture, source code, explanations, tests, and Git guidance.
4. User applies changes, runs tests, reports results, and commits.
5. Do not perform blind fixes; errors should be reported with logs/screenshots.
6. Git commit after stable milestones using clear conventional messages.
