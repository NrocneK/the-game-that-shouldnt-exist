# ADR-001 — Choose Phaser + TypeScript + Vite

## Status
Accepted

## Decision
Use Phaser 3 with TypeScript and Vite as the core technology stack.

## Reasons
- Suitable for 2D browser games
- TypeScript improves maintainability
- Vite provides a simple development/build workflow
- Phaser provides rendering, input, scenes, physics, and asset handling

## Consequence
The project targets the web first and uses Phaser Arcade Physics for MVP gameplay.
