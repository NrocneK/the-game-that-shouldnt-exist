# ADR-007 — MVP Scope First

## Status
Accepted

## Decision
Build a small playable vertical slice before expanding the full RPG.

## MVP
Starting Forest → Greenvale → Old Road → Forgotten Mine → Broken Miner.

## Reason
The project is long-term and must prove the core loop and architecture before large-scale content production.

## Consequence
Open world, multiplayer, advanced magic, multiple endings, full Administrator, The Null, and other large systems are explicitly deferred.
