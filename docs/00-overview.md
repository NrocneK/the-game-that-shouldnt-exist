# The Game That Shouldn’t Exist — Project Overview

**Version:** 1.0  
**Status:** Phase 0 Complete

## Project Role
- Assistant: Project Manager + Lead Game Engineer / Technical Lead
- User: Developer / Implementer / Tester

## Core Vision
A long-term 2D RPG Adventure game using an intentionally minimal stick-figure visual style and a richer fantasy world.

The game begins as a conventional fantasy RPG, then gradually reveals inconsistencies in its world. The mystery is discovered through gameplay, exploration, dialogue, quests, and the protagonist's unusual perception.

## Technical Baseline
- TypeScript
- Phaser 3
- Vite
- npm
- Git / GitHub
- Web target
- Phaser Arcade Physics
- Modular / Data-driven architecture

## Core Gameplay Loop
EXPLORE → DISCOVER → FIGHT → DEFEAT → LOOT → UPGRADE → QUEST/STORY → UNLOCK → EXPLORE DEEPER

## Mystery Loop
NORMAL WORLD → NOTICE STRANGE → USE WORLD SIGHT → DISCOVER CONTRADICTION → INVESTIGATE → STORY REVEAL

## MVP
The first playable vertical slice covers:
- Starting Forest
- Greenvale Village
- Old Road
- Forgotten Mine
- Broken Miner mini-boss
- Movement, jump, attack, dodge
- Basic combat
- HP / EXP / Level / Attack / Defense / Speed
- Inventory / equipment / potion / gold
- Main, side, and hidden quest
- Dialogue and story flags
- World Sight Stage 1
- Local save
- Basic HUD and audio

Phase 0 is complete. Development begins with Phase 1: Project Initialization.
